## Requisitos previos

- [Node.js](https://nodejs.org/) (versión LTS recomendada)
- [Git](https://git-scm.com/)

## Descarga

Clonar el repositorio:

```bash
git clone https://github.com/nachxg/challenge-final-qa-automation-xacademy-grupo5.git
```

Entrar a la carpeta del proyecto:

```bash
cd challenge-final-qa-automation-xacademy-grupo5
```

## Instalación

Instalar las dependencias (incluye Cypress):

```bash
npm install
```
